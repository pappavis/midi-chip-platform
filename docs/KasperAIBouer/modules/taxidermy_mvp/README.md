# MODULE — TAXIDERMY_MVP

## Doel
Hierdie is die eerste bewysmodule binne `KasperAIBouer`.

## Kernprobleem
’n Taxidermy besigheid het ’n workflow nodig wat:
- kliënt- en trofee-inname bestuur
- items korrek aan mekaar koppel
- foto’s / bewyse byhou
- approvals moontlik maak
- status vir kliënt sigbaar maak
- betalings- en finale afhandeling ondersteun
sonder dat die hele projek onmiddellik verander in ’n generiese CRM of volledige enterprise platform.

## Module-doel
Bou ’n beheerbare eerste MVP-spec en delivery basis.

## Fokus vir huidige fase
- source intake
- business framing
- functional scope
- infra reality check
- MVP cut
- eerste backlog

## Nie huidige doel nie
- volle globale CRM
- volledige WhatsApp automation
- finale shipping integrations
- accounting engine
- alle toekomstige modules

## Notes
WhatsApp bly belangrik as toekomstige rail, maar is nie verpligte MVP core dependency in hierdie kickoff nie.
