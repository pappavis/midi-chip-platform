# DECISION LOG POLICY

## Doel
Belangrike projekbesluite moet spoorbaar wees. Dit sluit in:
- database keuses
- hosting model
- integration scope
- auth strategy
- status model
- data-retention beginsels

## Minimum formaat
- Decision ID
- Datum
- Besluit
- Konteks
- Alternatiewe oorweeg
- Waarom hierdie besluit gekies is
- Gevolge
- Herbesoekvoorwaardes

## Reël
As 'n besluit later verander, word dit nie stilweg oorgeskryf nie. Die nuwe besluit verwys terug na die oue.
