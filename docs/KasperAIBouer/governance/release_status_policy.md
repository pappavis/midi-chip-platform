# RELEASE STATUS POLICY

## Doel
Dwing eerlike release-taal af.

## Verpligte taal
Elke release, module-handoff of demo moet eksplisiet sê:
- current status: Concept / Demo / MVP / Validated / Production Candidate
- wat ingesluit is
- wat nie ingesluit is nie
- grootste bekende risiko's
- aanbevole volgende stap

## Verbod
- Moenie 'production-ready' gebruik as validation en statusbewyse nog ontbreek nie.
- Moenie 'klaar' gebruik as daar net dokumentasie of net UI bestaan nie.
