# UTILITY PROMPT — REVIEW CYCLE

## Doel
Laat 'n artefak deur kritiese review gaan voordat dit as stabiel behandel word.

## Volgorde
1. Master bepaal review scope
2. Devil’s Advocate val swak plekke aan
3. QA toets logiese volledigheid
4. Release Manager merk artefak-status
5. Master besluit oor herwerk of gate pass

## Output
- review findings
- severity
- recommendations
- pass / rework status


## v0.2 preferred order
1. Functional and infra review
2. Devil's advocate challenge
3. QA completeness review
4. Release status assessment
