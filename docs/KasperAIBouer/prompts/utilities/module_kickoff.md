# UTILITY PROMPT — MODULE KICKOFF

Gebruik hierdie prompt om 'n nuwe module binne `KasperAIBouer` te begin.

## Prompt
Begin 'n nuwe module kickoff.

### Vereistes
1. Bevestig die module naam
2. Bevestig die huidige business probleem
3. Bevestig waarom hierdie module nou gebou word
4. Maak 'n eerste MVP cut
5. Maak 'n eerste out-of-scope list
6. Lys verwagte bronne in `references/`
7. Definieer eerste artefakte wat geskep moet word

### Output
- kickoff summary
- module goals
- success criteria
- MVP / not-MVP cut
- immediate source requests
