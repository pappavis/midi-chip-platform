# REFERENCES README

## Doel
Alle rou en afgeleide databronne vir `KasperAIBouer` modules word onder `references/` gehou.

## Voorbeelde van geldige bronne
- WhatsApp transkripsies
- call transkripsies
- voice note transkripsies
- PRD’s
- roadmaps
- mindmaps
- pricing sheets
- screenshots
- bestaande app notes
- legacy module docs
- inheritance bronne uit `sn76489builder`

## Basiese reël
As dit later nodig gaan wees om:
- te verifieer
- terug te lees
- te sintetiseer
- risiko’s op te spoor
- konflik in requirements op te los

dan hoort dit waarskynlik in `references/`.
