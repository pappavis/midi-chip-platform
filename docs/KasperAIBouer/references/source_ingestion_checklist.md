# SOURCE INGESTION CHECKLIST

- Is the source named according to convention?
- Is the source type clear? (transcript / voice note / PRD / pricing / visual / legacy)
- Is the date known?
- Is the author or source owner known?
- Does the source contain facts, ideas, or both?
- Are there contradictions with other sources?
- Does the source belong in inheritance, current module, or future module context?
