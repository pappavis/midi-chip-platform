# SCRUM OPERATING MODEL

## Core rhythm
1. Intake
2. Synthesis
3. Business framing
4. Functional framing
5. Infra review
6. Backlog slicing
7. Critical review
8. QA
9. Release/handoff

## Scrum rules
- No build without READY
- No done without explicit criteria
- Keep roadmap separate from sprint scope
- Surface blockers early
- Slice work small


## v0.2 refinement
The operating model now distinguishes four holding areas:
- discovery inputs
- active backlog
- parking lot
- validated release artefacts
