# PARKING LOT

## Doel
Hierdie dokument hou idees, toekomstige modules, strategiese rigtings en moontlike uitbreidings buite die huidige aktiewe scope, sonder om hulle te verloor.

## Reëls
- Niks in hierdie dokument is outomaties deel van die huidige sprint of huidige MVP nie.
- Items mag slegs uit hierdie dokument beweeg as `Master` en `ScrumMaster` dit saam toelaat.
- Parkeer idees hier eerder as om huidige scope te besoedel.

## Huidige geparkeerde rigtings
- CRM core abstrahering ná bewese taxidermy MVP
- WhatsApp pocket accountant
- diesel rebate module
- invoice extraction module
- advanced shipping integrations
- native mobile app strategies

## Item format
- Titel
- Waarom dit belangrik is
- Waarom dit nou nog nie ingesluit is nie
- Watter voorwaardes eers waar moet wees
- Wie dit later moet herevalueer
